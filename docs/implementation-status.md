Les appels et SMS restent désactivés par défaut. Aucun utilisateur, ligne ou événement fournisseur fictif n'a été ajouté à la base distante; la file de reprise SMS était vide après la migration. La configuration Twilio de l'application et les essais réels restent à faire. Les anciens credentials Twilio trouvés dans le plan ont été retirés du fichier, mais doivent être révoqués par leur propriétaire; la procédure sans valeurs secrètes est dans `runbooks/secrets-rotation.md`. Les commandes de base du dépôt pointent uniquement vers le projet Supabase hébergé; ne pas lancer Supabase local.

L'application mobile est sous `apps/mobile`; résultats et dépendances de signature/push sont décrits dans `docs/mobile-compatibility.md`. Les builds de bundle ne constituent pas une recette native. La phase desktop, le déploiement Railway et les essais téléphoniques attendent les identifiants d'environnement et les essais sur appareils. Le code de l'extension est prêt à être construit, mais doit être vérifié dans un Chrome réel.
